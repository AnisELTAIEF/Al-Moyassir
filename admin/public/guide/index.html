2. Présentation

Almoyassir (الميسّر) aide à lire, mémoriser et réviser le Coran, dans la riwaya de Qalun (mushaf libyen, 6214 ayat).

  • Qira’a (قراءة) : les 604 pages du mushaf. Boutons A− / A+ pour agrandir le texte ; la page défile alors jusqu’à sa fin.
  • Tahfidh (تحفيظ) : ayah par ayah, pour écouter, répéter (×3, ×5, ×10…) et mémoriser.
  • Révision (المراجعة) : ce que vous avez appris revient au bon moment pour ne pas l’oublier.
  • Prière : horaires de prière selon votre position, adhkâr et du‘â’.

Les 4 niveaux d’un ayah

NiveauSignification
Non apprisPas encore travaillé.
En coursEn cours de mémorisation.
AcquisSu par cœur. Il reviendra en révision.
À revoirSu, mais à retravailler (marqué par vous, ou révision en retard).

En Qira’a, un toucher sur un ayah le fait passer au niveau suivant ; un appui long ouvre sa fiche (écoute, tafsir, niveau).

3. Pour les membres

Créer son compte

  1. Installez l’app (Android) ou ouvrez la version web (iPhone, ordinateur) — voir § 1.
  2. Accueil → « Créer un compte ou se connecter » → « Créer un compte avec un code ».
  3. Saisissez votre code :
    • code d’invitation (8 caractères, ex. K7XQ-M2PA) reçu par e-mail : votre adresse et votre groupe s’affichent tout seuls ;
    • ou code du groupe (6 caractères) donné par votre responsable : indiquez alors votre adresse e-mail.
  4. Choisissez le nom affiché et un mot de passe (8 caractères au moins).

Déjà inscrit et invité dans un autre groupe ? Compte → « Rejoindre un groupe avec un code ».

Au quotidien

  • L’accueil propose de reprendre là où vous vous êtes arrêté, avec une suggestion (réviser, continuer la mémorisation).
  • Onglet Réviser : passages à réviser aujourd’hui ; récitez de mémoire puis touchez « J’ai révisé ». Rythme : 3 jours après l’avoir appris, puis tous les 7 jours.
  • Votre progression est enregistrée dans votre compte (sur tous vos appareils) et visible par les admins de votre groupe.

4. Pour les admins de groupe admin du groupe

L’admin d’un groupe suit la progression de son groupe et y fait entrer des membres. Il n’a pas accès aux autres groupes ni à l’administration générale.

Où gérer son groupe

  • Dans l’app : onglet « Suivi » → « Mes groupes » → votre groupe.
  • Sur ordinateur : l’admin web, rubrique « Mes groupes » (mêmes outils, grand écran, export CSV).

Le tableau de bord du groupe

  • Nombre de membres et d’admins, ayat appris au total, moyenne par membre, membres inactifs (7 jours et plus).
  • Liste des membres triable (nom, ayat appris, dernière activité), filtre « Inactifs seulement ».
  • Touchez un membre pour voir le détail de sa progression, sourate par sourate.
  • Exporter en CSV (admin web) pour un tableur.

Faire entrer quelqu’un

  1. Avec le code du groupe (le plus simple pour une classe) : copiez le code (6 caractères) et donnez-le. La personne choisit « Créer un compte avec un code ».
    • « Autoriser l’adhésion avec ce code » : décochez pour fermer temporairement le groupe.
    • « Nouveau code » : l’ancien ne marche plus (les membres actuels restent).
  2. Par e-mail : « Ajouter une personne » + son adresse (cochez « Admin du groupe » si besoin).
    • Si la personne a déjà un compte : elle est ajoutée tout de suite.
    • Sinon : une invitation est créée avec un code personnel ; l’e-mail est envoyé automatiquement si l’envoi est configuré, sinon copiez le message proposé et envoyez-le (e-mail, WhatsApp…).
  3. Par une liste (admin web, sur ordinateur) : dans le groupe, « Importer une liste » avec un fichier TXT ou CSV Nom complet ; E-mail — voir l’import.

Rôles, départs, invitations

  • Changer le rôle d’un membre : Membre ↔ Admin du groupe. Le groupe garde toujours au moins un admin.
  • Retirer un membre du groupe (son compte et sa progression sont conservés).
  • « Invitations en attente » : voir et révoquer une invitation non utilisée.
  • Renommer le groupe.

Conseil : une fois par semaine, filtrez les inactifs et prenez de leurs nouvelles. Un mot d’encouragement fait souvent repartir.

5. Pour l’administrateur général admin général

L’admin général gère tout le service. Il utilise surtout l’admin web sur ordinateur ; l’app propose aussi un onglet « Suivi et administration » (Aperçu, Utilisateurs, Invitations, Groupes).

Aperçu

Activité des 30 derniers jours, progression moyenne, les plus avancés, les personnes sans activité depuis 7 jours, invitations en attente.

Utilisateurs

  • Rechercher par nom ou e-mail ; exporter en CSV.
  • Rôle global : Utilisateur ou Admin général (le dernier admin ne peut pas être rétrogradé).
  • Désactiver un compte (bloqué immédiatement, réversible) ou le supprimer définitivement avec sa progression.
  • Mot de passe : générer un code de réinitialisation (voir § 7).
  • Groupes de la personne : l’ajouter à un groupe, changer son rôle dans chaque groupe.

Groupes

  • Créer un groupe (un code de groupe est créé automatiquement), le renommer.
  • Ouvrir un groupe : mêmes outils que l’admin du groupe (§ 4) — membres, code, invitations, rôles, CSV.
  • Désigner les admins de groupe : ce sont eux qui suivent leurs membres au quotidien.

Invitations

  1. Invitations → saisir l’e-mail.
  2. Choisir le rôle : Utilisateur, ou Admin général.
  3. Choisir un groupe (facultatif) et cocher « Admin du groupe » pour nommer un responsable.
  4. « Créer l’invitation » : l’e-mail adapté au rôle part automatiquement si l’envoi est configuré ; sinon « Copier le message » ou « Ouvrir dans ma messagerie ».

Suivi des invitations : en attente, acceptées, révoquées, expirées ; « ✉ envoyé » quand l’e-mail est parti ; révoquer une invitation en attente.

Import (plusieurs groupes d’un coup)

Menu Import : un fichier Groupe ; Nom complet ; E-mail ; Rôle. Les groupes absents sont créés, les admins de groupe nommés, les comptes existants ajoutés, les autres invités. Détails : import d’une liste.

Profil invitéCe qu’il reçoit

  • Le lien /invite/CODE de l’e-mail ouvre une page rappelant le code et les étapes.

Importer une liste d’utilisateurs

Pour inscrire beaucoup de personnes à la fois, depuis l’admin web (sur ordinateur). Un simple fichier texte (.txt) ou CSV (Excel : « Enregistrer sous → CSV »), une personne par ligne. Séparateur : point-virgule, tabulation ou virgule. Une ligne d’en-tête est acceptée ; les lignes vides ou commençant par # sont ignorées.

Exemple (import général) :

Groupe;Nom complet;E-mail;Rôle

  1. Choisissez le fichier (ou collez la liste), puis 1. Vérifier : une simulation affiche ce qui va se passer pour chaque ligne, sans rien modifier. Corrigez les lignes en erreur si besoin.
  2. 2. Importer : pour chaque ligne,
    • la personne a déjà un compte → elle est ajoutée au groupe (ou nommée admin du groupe) ;
    • sinon → elle est invitée : code personnel, son nom est pré-rempli à l’inscription, et l’e-mail d’invitation part automatiquement si l’envoi est configuré ;
    • déjà membre ou déjà invitée → rien n’est fait (relancer le même fichier ne crée pas de doublon).
  3. Télécharger le résultat (CSV) : la liste avec les codes et liens d’invitation, utile si l’envoi automatique n’est pas configuré (à transmettre par WhatsApp, e-mail…). Les codes ne sont plus affichés ensuite.

Une même personne peut apparaître dans plusieurs groupes : elle ne reçoit qu’un e-mail, et rejoint tous ses groupes en créant son compte. Limite : 1 000 lignes par fichier.

7. Mot de passe oublié

  1. La personne prévient un admin.
  2. L’admin (admin web → Utilisateurs → la personne → Mot de passe) génère un code de réinitialisation et copie le message.
  3. Dans l’app : écran de connexion → « Mot de passe oublié ? » → saisir le code et un nouveau mot de passe.

8. Questions fréquentes

« Appli non installée » sur Android

Installez le fichier arm64 (téléphones actuels). Si une ancienne version est présente dans un autre profil (dossier sécurisé, double appli), désinstallez-la d’abord.

Le code est refusé

Vérifiez qu’il n’a pas expiré ni été déjà utilisé, et que l’adresse saisie est bien celle de l’invitation. Sinon, demandez une nouvelle invitation.

Je ne vois pas l’onglet « Suivi »

Il n’apparaît que pour les admins (de groupe ou général). Demandez à l’admin général de vous nommer admin de votre groupe.

Ma progression sur iPhone et sur Android

Connectez-vous avec le même compte : la progression est synchronisée.

Les horaires de prière ne correspondent pas à ma ville

Prière → Réglages → « Me localiser », ou cherchez votre ville. Autorisez la localisation si le téléphone le demande.
